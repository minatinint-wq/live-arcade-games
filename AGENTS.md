# LIVE Arcade Games

Original implementations of interactive livestream games. Public MIT source.
Keep each game in its own module and meaningful commit. Names and interface
are Portuguese. Do not import Livecade source, images, sounds or credentials.
No API key, license token, personal data, browser state or production config
belongs in this repository. Use native Node and Canvas; no new dependencies.
Premium is a Hub distribution label; the public source remains MIT.
The Hub enforces its own signed licenses outside this repository.
Never connect a real live or broadcast in QA. Run npm test and verify UI.
Do not mark a module implemented until its mechanics run, respond to input,
have a visible renderer and pass the relevant behavioral checks.
